# 画面脚本 · MV001（末班地铁 · 夜归主线）


人物：林晚（27岁，夜班编辑，宽松针织衫+耳机）；城市：凌晨一点的南方城市，雨刚停，全程暖黄路灯。

开场｜末班车关门，空站台只剩一盏灯。林晚没有追下一班，抬头看了一眼线路图，把耳机戴上——耳机壳上映着站台暖光的弧线。
中段｜她走过天桥，路灯把水洼照成一块块暖色，镜头跟随脚步平移，城市在雨后微微发亮。她停在栏杆边看了一会儿城市的灯，耳机里只有雨声。
转折｜便利店的灯还亮着，她进去买了一杯热豆浆，店员打着哈欠把杯子递过来，热气在冷夜里很清楚。
收束｜她把这一天轻轻折进口袋，看了眼手机上的时间，在小区门口重新戴好耳机，走进没有雨的夜色。画面在缓慢拉远里收尾落版。
