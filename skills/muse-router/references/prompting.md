# Muse 提示词实战手册

以下结论来自 2026-11 的实测，不是官方文档复述。Muse Video 是 Meta 的预览模型，Meta 目前没有公开视频版提示词指南；能迁移的官方规范只有一条：多图按传入顺序读，可在文本里逐张标注。

## 1. 基本结构

一段自然语言，按顺序写：

1. **主体锚定**：图1是谁、不可变特征（与参考图逐字一致）
2. **动作**：一个主线动作，按时间顺序
3. **镜头**：景别 + 固定机位/轻微手持
4. **光线**：光源、色温、时间
5. **声音**：对白 / 环境声 / 音效 / 音乐
6. **文字处理**：文字物件失焦虚化

推荐 60–350 字。实测 59 字极简版与 250 字自然语言版都优于 722 字结构化模板。

### 不要写

- `subject_definitions` / `retention_analysis` / `overall_soundscape` 等分节
- `[Shot 2] At 00:03.500 —` 这类毫秒时间码（多镜头用 `[3.2-6.4秒]` 即可）
- 与参考图冲突的外貌词
- `seed`、`negative_prompt`、首尾帧、参考视频

## 2. 否定句：基本无效

一组对照里，两个 prompt 只差否定句（“不要卷发 / 不要金色滤镜 / 不要过曝”），成片 **MD5 完全一致**。另一组写“明显降低暖黄色调、避免偏黄偏橙”，结果过冲到青蓝夜戏（黄度 -27.8、饱和 51%）。

结论：
- 控色用正面参数：柔和散射自然光、中性白平衡、低饱和奶油色调。
- 锁动作/发型用独立一段的“保持……”陈述句，不要写“不要……”。
- 单独的“保持……”成段有效；塞在风格句尾则完全没生效。

## 3. 参考图指代

固定顺序 + 逐条声明：

```
图1是女主角：长发及胸、自然直发、米色针织开衫，五官、发型、服装严格与图1一致。
图2是场景：夜晚出租屋，书桌、台灯、窗外城市灯光，布局、光线严格与图2一致。
图3是道具：手机，外观、屏幕光感严格与图3一致。
```

- 一图一职责，不要塞多张同类图。
- 不写文件名。
- 多视图设定图：不会拼贴，人物稳定；但会复刻设定图里的脸。二次生成的设定图等于换锚点。

## 4. 多镜头

```
横屏 16:9，一条 10 秒视频，包含 3 个镜头，镜头之间硬切，不做转场。

图1是曹操：……
图2是场景：……

[0.0-3.2秒] 镜头1（图1、图2）：曹操沿石阶走下。中景跟拍。
[3.2-6.4秒] 硬切至镜头2（图1、图2）：曹操停在大象前，仰头打量。中近景，固定机位。
[6.4-9.8秒] 硬切至镜头3（图1、图2）：曹操抬手发问。近景，固定机位。
```

- 切点比提示词早约 1 秒。
- 最后一段写到 9.5s，留余量。
- 可以跨场景，把场景图都放进去并在镜头块点名。
- 一镜一个说话人，方便口型对齐。

## 5. 声音与对白（重点）

Muse 的音频与画面一起生成并同步，不是后期贴的。

### 对白

把台词原样写进提示词，标明说话人、音色、语气：

```
曹操（中年男声，压低嗓音）问：“这头象，到底有多重？”
曹冲（七岁男童，清亮）抬头说：“我有办法。”
```

要点：
- 一句台词放一个镜头，别让两个人同时说话。
- 台词长度控制在镜头时长内；中文大约每秒 4–5 字。
- 说话人的脸要可见，别背对镜头、别在大幅运镜中说话，否则口型对不上。
- 音色描述越具体越好（年龄、性别、粗细、情绪）。

### 环境声 / 音效

```
环境声：河水轻拍船帮，木跳板吱呀，远处人群低语。
音效：刀刃刻木的细响。
```

会生成对应的声音并与动作大致同步（脚步、落水、刻木这类）。

### 音乐

可以写风格/情绪（`低沉鼓点渐起`、`温暖钢琴`），但模型对结构、卡点、段落控制有限；正式配乐通常还是后期做。

### 静音

API 关不掉音频（`audio:false` 返回 400）。项目需要静音时，生成后在剪辑里 `-an` 或替换，不要指望提示词里的“无配乐/无对白”能完全压住。

## 6. 风格与色温

模型默认偏暖，源图即使是冷调，成片也常 +1～+9 黄度。

| 写法 | 黄度 | 结果 |
|---|---|---|
| 无风格词 | +4.9 | 自然略暖 |
| 日韩治愈系 + 奶油色调 | +16.0 | 更黄更糊，发色变棕 |
| 再加“降低暖黄/冷白平衡” | -27.8 | 过冲青蓝夜戏 |
| 只加“中性白平衡” | +2.9 | 最中性但不甜 |
| 治愈系 + 阴天散射光 | -9.9 | 干净偏冷，动作丢失 |
| 治愈系 + 散射光 + 中性白平衡 + 锁动作/直发 | -1.7 | 干净柔美，动作保留 |

- “日韩治愈系”自带暖黄+过曝+窗边逆光的刻板印象，单加会更黄。
- 控色靠灯光/白平衡词，不靠否定句。
- 风格词会改调度：容易把“快步走”变成“窗边静态肖像”、直发变卷发；需要时用独立一段“保持上述动作与跟拍”“保持自然直发”。
- 多段成片统一调色建议后期 LUT，不要逐条压色温。

## 7. 内容审核

- 亲密/医疗/暴力动作容易触发 `content_policy_violation`：手背贴额头、抚摸脸、砍杀手势都实测被拦。
- 改成非接触动作：“替他拢紧领口”“把外套披到肩上”“抬手指向远处”。
- 失败任务不扣费，改提示词重提。

## 8. 常见画面问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 人物换脸/换发型 | 提示词与参考图冲突 | 外貌描述逐字对齐参考图 |
| 构图越走越偏 | 写了推拉摇移 | 固定机位 |
| 背景文字乱码 | 机场/手机屏幕/旗帜 | 写“失焦虚化”；镜头控制在 3s 内 |
| 人物被复制/肢体粘连 | 人多的大场面 | 减少同框人数，用景别避开 |
| 口型对不上 | 说话人背对/运镜中说话/台词太长 | 正面近景、固定机位、缩短台词 |
