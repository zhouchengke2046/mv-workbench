- **不要默认直接跑**；先给模型卡，用户确认。
- Muse API 路径：Router `POST /v1/videos` → `GET /v1/videos/{id}` → `/content`。
- Key 从 `~/.config/mv-workbench/keys.json` 读；生成命令走 `mv_keys.py exec --need ... --`；RunningHub 与 Router 两份 key 不混用。
- 模型卡至少包含：模型/工作流 ID、参考图上限、时长/分辨率、音轨、单价、已知失败、提示词 skill。

## 2. 提示词路由（禁止跨模型复用）

| 内容 | 模型 | 写提示词的 skill/参考 | 硬要点 |
|---|---|---|---|
| 音乐 | ACE-Step | `ace-music` | 英文标签四类（曲风/人声/情绪速度/乐器质感）+ 结构标记歌词 + 秒数；不是自然语言长文 |
| 图片 | MOSS | `zz-manju-image-prompts` | 中文详细；固定负面；角色逐项锁；产品用实拍；2MP/9:16 |
| 视频 H3 | YZ金鱼多参 | `h3-prompt-writing` | 结构化；图1/图2点名；动作连续；颜色/场景锁死；不要文字/语音 |
| 视频 Muse | Muse | `muse-router/references/muse_video_prompt_guide.md` | 自然语言单段；参考图按传入顺序点名；**静态三脚架，不写推拉摇移**；不要时间码 |
| 口型 | S2V | `h3-prompt-writing` / S2V | 音频驱动，单独模型；只在需要真人唱歌对口型时 |

- 先出 **1 条样板 prompt**（第一条 MV/第一段）给用户看，确认格式/参考图映射后再批量。
- 每个 prompt 必须带**参考图 map**：图1=角色A、图2=场景、图3=道具；不写文件名。
- prompt/参考图/参数落盘（`prompts/`、`clip_manifest`），和生成版本绑定。
- Muse 没有官方提示词规范，用实测指南；ACE 是标签不是自然语言；**不能拿 H3/Muse 的 prompt 直接互喂**。

## 3. 参考图 map（多参视频）

```
图1 = 角色A（四视图/定妆照）
图2 = 场景（场景板）
图3 = 道具/产品（产品用实拍）
```

- **一图一职**；不要堆满；不超过模型上限（H3 6 / Muse 9，以工作流为准）。
- prompt 里逐条写“五官/发型/服装严格与图1一致；场景布局/光线与图2一致；产品外观与图3一致”。
- 参考图是**条件引导**，不锁首帧/构图；景别、机位、动作、光线写在 prompt。
- 参考包变更 = 所有依赖它的视频段 `stale`。

## 4. 模型特定硬规则

### ACE-Step
- 标签英文、逗号分隔；歌词带 `[intro-short]`/`[verse]`/`[chorus]` 结构标记；时长用秒。
- 生成后试听：咬字、风格、速度/情绪、时长；不合格改标签/歌词，不换模型硬撑。
- 定稿后必须出逐句时间轴；视频按时间轴裁。

### MOSS
- 中文详细一句话：主体+外观逐项+动作+场景+光线+镜头感；负面固定。
- 同一角色每张重复完整描述；服装颜色逐字写；产品图用实拍，不生成。

### H3 多参（YZ金鱼）
- 用多参工作流；**不要用 I2VA 单首帧工作流**。
- 结构化提示词；动作连续；颜色/场景特征锁死；画面不要文字/语音。
- 竖屏优先 YZ金鱼（按 MP 计费）；坚持 H3 I2VA 会踩 547 币/4.5s 的坑（legacy）。

### Muse
- 自然语言单段，200–350 字；参考图按传入顺序点名。
- **静态三脚架**：不写推拉摇移；轻微推镜靠后期裁切。
- 不写时间码（会变 7.4s）；10s 多镜硬切用文字描述。
- 文字/屏幕/指示牌写“失焦虚化”；内容审核可能拦动作，准备改写。
- API 路径：Router `POST /v1/videos` + `GET /v1/videos/{id}` + `/content`。
- TokenTech 实测（2026-11-13）：`{"model":"muse-video-ext","prompt":"...","seconds":2,"resolution":"720p","size":"720x1280"}` → 2.000s / 720×1280 / 24fps / H.264+AAC，76s 完成；**2s=¥1.00，10s≈¥5.00**（billing_expr 是 USD，×7.3）。
- 参考图字段仍待实测（`image_urls` / `input_reference` / 单个 `image`）；400 校验失败不扣费，200 建任务才扣费。

### S2V
- 只在需要真人唱歌对口型时用；音频驱动，8s，480×832/16fps；后接 Topaz 超分。

## 5. 样板、批量、版本

- 每个新模型/新 prompt 组合先跑 **1 条 MV/1 段**；用户看样；通过才批量。
- 第一条/第一个风格包全审；其余抽检；用户点名才细看。
- 每次记录：model/workflow、prompt、refs、params、seed、cost、time、版本号。
- 模型/提示词变更 = 新版本；旧视频保留历史；音乐 `locked` 不可改。
