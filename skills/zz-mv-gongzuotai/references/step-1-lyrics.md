# 步骤 1 · 歌词（只管歌词）

纯对话创作，0 币。本步只产出歌词；曲风、时长预估都服务于下一步音乐生成。

## 输入（缺就问，一次问全）

1. 产品：名称、形态、核心卖点 2–3 个（如"42dB 主动降噪"）
2. 场景/情绪基调：通勤解压 / 旅行自由 / 毕业远行 ……
3. 风格：3d / lip-sync / drama（决定歌词的镜头感强弱）
4. 时长目标：默认 24–45s
5. 主角设定（可选）：名字、外貌——歌词步先收集，图片步直接用
6. 参考视频（可选）：对标已拆过配方，见下

## 配方（3 条对标视频共同点）

- **剧情歌词**：讲一个有"冲突→转折→和解/种草"弧的微型故事，不是卖点清单
- **产品=戏眼**：产品出现在转折点上（戴上耳机那一刻世界安静 / 拉上箱子那一刻说走就走）
- **卖点翻译**：参数翻成体感和画面（"45dB 降噪"→"把整条地铁的喧嚣按了静音"），不喊参数
- 弧线模板：日常痛点（1–2 句）→ 产品介入转折（1–2 句）→ 情绪高潮/副歌种草（2–4 句）→ 收尾记忆点（1 句）

## 硬约束

| 项 | 约束 | 原因 |
|---|---|---|
| 结构标记 | `[intro-short]` `[verse]` `[chorus]`（ace-step 直接吃） | 音乐步参数格式 |
| 行数 | 45s ≈ 10–14 行正文；24s ≈ 6–8 行 | 每行 ≈ 3.5–4.5s |
| 每句字数 | ≤ 12 字，超了拆行 | 卡拉OK字幕一行放得下 |
| 押韵 | 全篇统一韵脚（ang/an/ao/ai/ou/i 常用），副歌句句押 | 唱感 |
| 产品名 | 出现 1–2 次，放副歌 | 记忆点 |
| 开头 | `[intro-short]` 后 3 秒内进正题 | 短视频完播率 |

## 出稿

一次出 **2–3 版**（不同切入：痛点切入 / 场景切入 / 人物切入），每版完整贴在对话里 + 存文件：

```
01-歌词/歌词_v1.md
```

文件格式：结构标记 + 歌词正文；文末 3 行元信息（韵脚 / 预计时长 / 故事一句话）。
state：`versions[]` 追加、status=`reviewing`。

## 修改循环

- 点名哪句改哪句；改完贴**改动前后对照**（只贴动过的句），全文存新版
- 方向性反馈（"再轻一点"）→ 先给一句改法示例，认可后再全改
- 定稿前自查：结构标记齐 / 每句 ≤12 字 / 韵脚统一 / 产品名 1–2 次 / 行数×4s ≈ 目标时长

## 定稿后

`final` 指向定稿文件，status=`locked`。提醒用户：音乐每跑一版 39 币，歌词尽量一步到位再进第 2 步。
