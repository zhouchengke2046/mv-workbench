# H3 视频提示词方言（model: minimax-h3-rh-ck）

> **按模型选方言**：`minimax-h3-rh-ck` → 本文件；`muse-video-ext` → `muse.md`。
> 不要把 muse 的时间线短式塞给 H3，也不要把 H3 的八段长文塞给 muse。
> 官方原文指南在本目录 `h3/base-en.txt`、`h3/ref-en.txt`（MiniMax 官方照搬）；本文件是 MV 实用配方。

## 模型事实（Router /api/pricing 公开参数）

| 项 | 值 |
|---|---|
| API | `POST /v1/responses`（任务协议，同 ace/moss）——**不走 /v1/videos** |
| 参数 | 只认 `metadata.nodeInfoList`（nodeId/fieldName/fieldValue 直通 RH 节点） |
| 关键节点 | `155.index` 模式（0=文生 1=首尾帧 2=多参+音频）、`20.value` 秒数（推荐 10-15）、`121.index` 分辨率（6/5=高 4=640 平衡 2/1=快速试错）、`123.aspect_ratio` 比例（9:16）、`43.text` 文戏提示词、`47/112/113/114/115/131/133/247/250.image` 参考图（最多 9 张）、`116/135/136.audio` 音频 |
| 代价 | 按 RH 运行时长实扣；H3 比 muse 贵，先用 121.index=1（480）快速试错 |
| 未实测 | 参考图槽位的 fieldValue 形态（URL 直传待验证）——首用先 1 张试 |

## 方言特征：八段长文（43.text）

H3 的 43.text 吃**结构化长文**（官方八段），每段有标题行。muse 的短时间线式会被 H3 稀释执行。

### 固定结构（43.text 按序）

1. `**影片目标与核心概念**`：一句说清本段讲什么、情绪转折在哪。
2. `**固定人物、主体、场景与一致性**`：角色卡锚点全量照抄（年龄/发型/服装/配饰/固定辨识组合）+ 场景锚点；"任何镜头不得增删改"。
3. `**0—N秒时间线与动作表演**`：逐 0.5-1s 细分动作/视线/道具状态；有台词/OS 时写明嗓音与情绪。
4. `**剪辑、摄影与表演规则**`：机位/运镜/切镜依据/微表情重点。
5. `**视觉风格与材质**`：色温、材质细节（布料褶皱、金属光泽、皮肤质感）。
6. `**声音设计**`：环境音、画外音方位、台词气声（H3 原生立体声）。
7. `**收束结果**`：结尾画面定格在哪、关系/情绪落在哪。

## 调用配方（Router 任务协议）

```bash
python3 scripts/mvwb.py keys exec --need router -- python3 - <<'PY'
# POST /v1/responses
# {"model":"minimax-h3-rh-ck","input":"...","background":true,
#  "metadata":{"nodeInfoList":[
#    {"nodeId":"155","fieldName":"index","fieldValue":"2"},   # 多参模式
#    {"nodeId":"20","fieldName":"value","fieldValue":10},      # 秒数
#    {"nodeId":"121","fieldName":"index","fieldValue":"4"},    # 分辨率 640
#    {"nodeId":"123","fieldName":"aspect_ratio","fieldValue":"9:16"},
#    {"nodeId":"43","fieldName":"text","fieldValue":"<八段长文>"},
#    {"nodeId":"47","fieldName":"image","fieldValue":"<参考图URL>"}  # 形态待验证
#  ]}}
PY
```

- 轮询/产物与 moss/ace 同（`GET /v1/responses/{id}` → artifact URL）。
- **首用纪律**：`121.index=1`（480 快速试错）+ `20.value=10` 单次试跑，确认参考图形态与成本后再上高质量。
- 一致性是 H3 的卖点（多参模式 155.index=2），但先小样验证参考图通道，再批量。
