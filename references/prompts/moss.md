# MOSS 资产图提示词壳

**定位**：MOSS 资产图的"写法壳"。把角色/道具/场景的版式与格式固化为默认，避免每个项目手写一遍。

**边界**：只写提示词，不生成图、不调供应商、不改其它 skill 的方法论。

## 输入 → 产出

| 有 | 做法 | 产出 |
|---|---|---|
| `视觉设定.md` + 项目画幅/风格 | 逐 `IMG-*` 写双语可复制正文 | `图片提示词.md`（每条含 zh 与 en 两块） |
| 已有 `图片提示词.md` | 按本文口径补齐/改写，保留原 id 与文件命名 | 同文件 vN |

下游：MOSS 资产图（RunningHub workflow `2116462203997081601`）消费 `图片提示词.md` → `coding/assets.json`。

## 强制规则（缺一即不合格）

1. **双语双块**：每条 `IMG-*` 必须有两个 ` ```text ` 块，**先 zh 后 en**；两份事实逐项等价（同一锚点、同一版式、同一负向），禁止英文自由扩写、缩写事实或漏掉连续性锁。
2. **角色 = 三视图**（16:9）：左格正面面部特写（头肩）；中格正面全身但**头部完全不入画**（画面从锁骨/领口以下起，不出现脸、头发、脖颈断面）；右格背面全身（示发界与服装背面）。**纯色无缝背景**（同一角色统一底色）、中性表情、无道具；三格同一人/同服/同光、比例一致、脚底对齐；**不要四视图**。
3. **道具 = 多视图**（1:1）：至少正视图 + 侧视图（必要时加顶视或局部），同一物体同一光照；**纯色干净背景**；无手、无人、无环境；尺度参照可选，不默认用手。
   · **例外**：细节/状态特写（`IMG-D*`）→ 1:1 微距特写，允许虚化背景，不做多视图（如裤脚草籽、磨损局部）。
4. **场景 = 空镜**（16:9，跟项目画幅）：**无人**（人物/动物一律不入画，剧情占用需项目另行声明）、**大全景**、**45° 俯视**（俯拍视角）；写清固定锚点与光向。

## 单条结构（zh 与 en 各自完整一遍）

【用途】→【画风】→【版式】→【锚点（身份/工业/地理）】→【姿态/状态】→【背景】→【布光】→【文字政策】→【负面】

- **负面四类**：版式误读（不要四视图/不要加格）、身份漂移（不要换装/不要X）、画质（不卡通/不畸形/不磨皮）、文字（无文字/水印/logo）。
- **负向回弹警示**：不要把我想要排除的徽章/图案写成"颜色+形状"清单——实测会反向诱发（点名蓝色圆标后生成更大徽章）。用正向限定（"服面只有橙色条纹一种装饰"）代替点名负向。
- **连续性锁**原样进两份正文。
- 文字政策按项目文字要求二选一，zh/en 必须一致。

## 命名与落位

- id：`IMG-<C|S|P><nn>`（C=角色、S=场景、P=道具）。
- 文件：`assets/<id>-<名称>.png`；必须与 `coding/data.js` 的 `ASSETS[].file` 逐字一致。
- 场景/角色 16:9、道具 1:1；2MP（MOSS 出图参数由 RunningHub provider 负责，本参考只声明）。
